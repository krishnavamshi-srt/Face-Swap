# Face swap, local and offline
1. Install Node.js 18+.
2. In this folder run: `npm install` (needs internet once: fetches the engine and a 4 MB face model).
3. Run: `npm start`, then open http://localhost:3000 (use `npm start -- --lan` to open it from a phone on the same Wi-Fi).
After step 2 you can disconnect. Everything runs in your browser; nothing is uploaded.
Best in current Chrome, Edge or Firefox. Video is saved as WebM.
